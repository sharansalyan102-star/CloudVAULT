\# ☁️ CloudVault – Secure Cloud File Storage System



\## 📌 Project Overview



CloudVault is a secure and user-friendly cloud file storage application that allows users to upload, store, manage, download, and organize their files through a web-based interface.



The application provides user authentication and file management features with a simple and intuitive dashboard. It aims to make file storage and retrieval convenient while maintaining data security.



\## 🎯 Objectives



\- Provide a simple and intuitive file storage platform.

\- Enable secure user registration and login.

\- Allow users to upload and download files.

\- Organize files efficiently.

\- Provide file management features such as starring, deleting, restoring, and viewing recent files.

\- Develop a responsive and user-friendly dashboard.



\## ✨ Features



\- \*\*User Authentication\*\* – User registration and login.

\- \*\*File Upload\*\* – Upload files to CloudVault.

\- \*\*My Files\*\* – View uploaded files.

\- \*\*Recent Files\*\* – Access recently uploaded files.

\- \*\*Starred Files\*\* – Mark important files.

\- \*\*Trash Management\*\* – Delete and restore files.

\- \*\*File Download\*\* – Download stored files.

\- \*\*User-Friendly Dashboard\*\* – Simple and intuitive interface.

\## ⚙️ Installation and Setup



\### 1. Clone the Repository



```bash

git clone https://github.com/sharansalyan102-star/CloudVAULT.git

cd CloudVAULT

```



\### 2. Setup Backend



```bash

cd backend

npm install

```



Configure the required environment variables and database connection.



Start the backend server:



```bash

npm start

```



\### 3. Setup Frontend



Open a new terminal:



```bash

cd frontend

npm install

npm run dev

```



\### 4. Access the Application



Open the frontend URL displayed in the terminal, typically:



```text

http://localhost:5173

```



The backend API runs on:



```text

http://localhost:5000

```



\## 🔐 Security



CloudVault incorporates user authentication and backend middleware to protect user-specific functionality. Sensitive credentials should be stored using environment variables and should never be committed to GitHub.
